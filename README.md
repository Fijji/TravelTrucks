# Travel Trucks Project

This project is a web application for browsing and booking campers, built using React, Redux, and Vite. 
The app allows users to filter, view, and book different camper models based on their features.

Make sure you have the following installed:

    Node.js (version 14 or later)
    npm

1. Clone the repository:
   https://github.com/Fijji/TravelTrucks.git
2. Go to the project directory
3. Install dependencies:
   npm install
4. Start the project -> ➜ Local: http://localhost:5173/:
   npm run dev

Key Features

    Catalog Browsing: Explore different camper models with their details.
    Filters: Filter campers by location, features, and vehicle types.
    Booking: Book a camper through a simple form.
    Favorites: Mark and save favorite campers for easy access.

Technologies Used

    Frontend: React, Redux, CSS Modules, React Router
    Backend: Mock API with JSON data (can be replaced with real backend)
    Build Tool: Vite
